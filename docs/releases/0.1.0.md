# Midgard 0.1.0 — Ignition

First minor release of the provider-neutral communication/routing layer and a
component of Ignition Phase 1 / IGNITION-001.

## Included

- Core-facing communication channel;
- explicit Butler target routing through neutral AsgardTarget ports;
- correlation preservation;
- structured routing/channel errors;
- canonical source Butler identity checks;
- visible Butler directory projection;
- provider-neutral tracing hooks;
- node-manifest aggregation for Core-side and Butler-side descriptors.

## Ignition paths

Public Core-facing path:

```text
Interphone -> Bifröst -> Midgard -> Core -> HAP -> Home Assistant
```

Private proving branch:

```text
Interphone -> Bifröst -> Midgard -> Butler-owned Asgard -> Alfred
```

## Boundary

Midgard does not contain a concrete Butler runtime or concrete Asgard
implementation. It owns communication/routing semantics, not household or
runtime behavior.

## Deferred

- reusable standalone Asgard;
- richer inline Butler addressing;
- profile presentation metadata;
- user preference/default-Butler policy.
