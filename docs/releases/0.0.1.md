# Midgard 0.0.1

First Public Alpha checkpoint of the provider-neutral Butler communication layer.

## Included

- Core-facing communication channel;
- explicit Butler target routing through neutral AsgardTarget ports;
- request correlation preservation;
- structured routing/channel errors;
- canonical source Butler identity checks;
- visible Butler directory projection;
- provider-neutral tracing hooks;
- node-manifest aggregation for Core-side and Butler-side descriptors.

## Live proving

The 0.0.1 line was proven in the canonical Bifröst -> Midgard path with
preserved request identity and observable READ -> ACTION -> READ/VERIFY behavior.

## Public boundary

Midgard does not contain a concrete Butler runtime or a concrete Asgard
implementation. Those are consumers of its neutral ports. Core-facing use does
not require a concrete Butler target.

## Deliberately deferred

- reusable standalone Asgard package;
- richer inline Butler addressing;
- profile presentation metadata;
- user preference/default-Butler policy.
